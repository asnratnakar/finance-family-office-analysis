# UI Screenshots

These folders contain synthetic-data UI evidence for preserving the existing application.

- `baseline/` is the current app before migration or redesign.
- `migrated/` is the app after a migration or rebuild.

Never place real account statements, balances, bank exports, brokerage exports, API keys, or personally identifiable names in screenshots.

Use the browser capture script:

```powershell
python scripts/capture_ui_baseline.py
```
